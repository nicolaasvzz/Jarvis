How to read this

Every agent in the pool is one character. When the pool hands it a step, the tool decides the room — files go to the Archives, browser work to the Web Wing — and the agent walks there, sits at a free desk and shows three dots while the tool runs. Independent steps of the same plan run side by side, so several agents work at once.
